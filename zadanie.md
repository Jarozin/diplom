## Задание диплом

Тема: Метод поддержки принятия решений в рамках выполнения пошаговой инструкции, заданной в графовом формате

## 1. Аналитический раздел
Провести анализ предметной области систем поддержки принятия решений, сопровождающих выполнение набора предписаний человеком. 
Провести сравнительный анализ методов принятия решений. 
Описать существующий графовый формат описания инструкций, представляющих выполняемый человеком набор предписаний. 
На примере выбранного домена формализовать классы возможных состояний, событий и связанных с ними действий.
Формализовать постановку задачи в виде функциональной модели.

## 2. Конструкторский раздел
Разработать метод поддержки принятия решений в рамках выполнения пошаговой инструкции, заданной в графовом формате.
Описать основные особенности предлагаемого метода.
Сформулировать ограничения предметной области.  
Изложить ключевые этапы метода в виде функциональной модели и схем алгоритмов.
Выделить структуры данных, необходимые этому методу.

## 3. Технологический раздел
Обосновать выбор средств программной реализации. 
Разработать программное обеспечение, реализующее представленный метод, и выполнить его тестированиие. 
Описать взаимодействие пользователя с программным обеспечением.

## 4. Исследовательский раздел
Описать исследовательскую процедуру. 
Составить набор сценариев развития событий для каждой решаемой задачи из набора задач в рамках выбранного домена, включая различные виды нештатного развития ситуации. 
Выполнить параметризацию метода согласно описанной исследовательской процедуре.
Дать рекомендации о применимости метода.
