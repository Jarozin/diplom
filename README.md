Вы правы. Уточним логику.

В каждом сеансе:
- Время подготовки \(t_{\text{prep}} = 5\) минут.
- Максимальная продолжительность сеанса \(T_{\text{max}} = 120\) минут (2 часа).
- Время на продуктивную работу: \(T_{\text{work}} = T_{\text{max}} - t_{\text{prep}} = 115\) минут.
- Среднее время на одно сравнение \(\tau = 42\) секунды \(= 0.7\) минуты.

Тогда максимальное количество сравнений, которое эксперт может выполнить за один сеанс:

\[
N_{\text{max}} = \frac{T_{\text{work}}}{\tau} = \frac{115}{0.7} \approx 164.
\]

Необходимое количество сеансов для выполнения \(N\) сравнений:

\[
S = \left\lceil \frac{N}{N_{\text{max}}} \right\rceil = \left\lceil \frac{N}{164} \right\rceil.
\]

Общее время подготовки:

\[
T_{\text{prep, total}} = S \cdot t_{\text{prep}} = S \cdot 5 \text{ минут}.
\]

Чистое время разметки:

\[
T_{\text{work, total}} = N \cdot \tau = N \cdot 0.7 \text{ минут}.
\]

Общее время:

\[
T_{\text{total}} = T_{\text{prep, total}} + T_{\text{work, total}} = 5S + 0.7N \text{ минут}.
\]
