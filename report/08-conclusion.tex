\chapter*{ЗАКЛЮЧЕНИЕ}
\addcontentsline{toc}{chapter}{ЗАКЛЮЧЕНИЕ}

В ходе выполнения данной работы была достигнута поставленная цель: исследованы известные методы сопровождения пользователя при выполнении инструкций.

Также были решены все поставленные задачи:
\begin{itemize}
	\item проанализирована предметную область систем поддержки принятия решений;
	\item формализована задачу поддержки принятия решений при выполнении предписаний человеком;
	\item описан существующий графовый формат описания инструкций;
	\item на примере выбранного домена формализованы классы возможных состояний, событий и связанных с ними действий;
	\item описаны известные подходы к планированию следующих действий и провести их сравнительный анализ.
\end{itemize}
