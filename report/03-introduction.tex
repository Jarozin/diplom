\chapter*{ВВЕДЕНИЕ}
\addcontentsline{toc}{chapter}{ВВЕДЕНИЕ}

Данная научно--исследовательская работа посвящён предметной области поддержки принятия решений.
Целью данной НИР является исследование методов сопровождения пользователя при выполнении инструкций.

Для достижения поставленной цели необходимо выполнить следующие задачи:
\begin{itemize}
	\item проанализировать предметную область систем поддержки принятия решений;
	\item формализовать задачу поддержки принятия решений при выполнении предписаний человеком;
	\item описать существующий графовый формат описания инструкций;
	\item на примере выбранного домена формализовать классы возможных состояний, событий и связанных с ними действий;
	\item описать известные подходы к планированию следующих действий и провести их сравнительный анализ.
\end{itemize}
