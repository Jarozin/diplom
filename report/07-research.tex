\section{Сравнение классического и модифицированного МАИ}

Ранее в работе уже была дана оценка количества необходимых сравнений для классического МАИ и его модификации. 
Для практического применения разработанного метода можно оценить, сколько времени требуется эксперту для разметки одного попарного сравнения.
Эта оценка позволяет прогнозировать общую трудоемкость подготовки конфигурационных файлов для новых предметных областей.

Целью данного исследования является определение необходимого на практике количества времени в среднем для разметки попарных сравнений для реализованных модификаций метода. 
Также необходимо провести сравнение модификаций метода по количеству необходимого времени работы эксперта.

\subsection{Описание исследовательской процедуры}
\textbf{Этап 1. Формирование набора данных для разметки.}
Для проведения эксперимента был сформирован набор попарных сравнений, включающий:
\begin{itemize}
\item сравнения критериев между собой (5 критериев: безопасность, полезность, актуальность, срочность, критичность);
\item сравнения альтернатив по каждому критерию для различного количества альтернатив (5, 10, 16, 20, 30, 50).
\end{itemize}

Каждый эксперт получал одинаковый набор размечаемых данных для обеспечения сопоставимости результатов.

\textbf{Этап 2. Подготовка экспертов.}
Перед началом измерений каждый эксперт был ознакомлен со шкалой относительной важности Саати (1---9) и принципами заполнения матриц попарных сравнений.

Каждый эксперт выполнял тренировочный сеанс из 5 сравнений для ознакомления с процессом, результаты которого не учитывались в итоговой статистике.

\textbf{Этап 3. Проведение сеансов разметки.}
Каждый эксперт проводил 10 сеансов разметки с различным необходимым количеством попарных сравнений (от 5 до 100). Параметры сеансов фиксировались в таблице. 
Во время сеанса обеспечивалось следующее:
\begin{itemize}
\item эксперт работал в спокойной обстановке без отвлекающих факторов;
\item запрещалось делать перерывы внутри сеанса;
\item фиксировалось время начала и окончания сеанса.
\end{itemize}

Исследовательская процедура проводилась со следующими допущениями.
\begin{itemize}
    \item Процесс разметки состоит из последовательных сеансов работы.
    \item Каждый сеанс включает фазу <<подготовки>> (вхождения в контекст экспертом) и фазу непосредственной разметки.
    \item Время подготовки \(t_{\text{prep}} = 5\) минут считается постоянным для каждого сеанса.
    \item Разметка каждого сравнения считается независимой операцией с постоянным средним временем \(\tau\).
\end{itemize}

\subsection*{Обработка результатов}

Для каждого сеанса вычислялось время разметки одного сравнения:
\[
\tau = \frac{T_{\text{total}} - t_{\text{prep}}}{n},
\]
где \(T_{\text{total}}\) --- общая продолжительность сеанса, \(t_{\text{prep}} = 5\) минут --- время подготовки.

Результаты показали, что среднее время \(\tau\) составляет приблизительно 42 секунды на одно попарное сравнение. 
Минимальное зафиксированное время составило 36 секунд (при малом количестве сравнений), максимальное --- 43 секунды.

\subsubsection{Зависимость времени от количества сравнений}

Среднее время разметки одного сравнения составляет \(\tau = 42\) секунды. 
Время подготовки принято равным \(t_{\text{prep}} = 5\) минут на каждый из $S$ необходимых сеансов.
Тогда общее время для \(N\) попарных сравнений выражается формулой:
\[
T(N) = S \cdot 5 + \frac{42}{60} \cdot N \quad \text{минут}.
\]

Так как длительность каждого сеанса составляет 2 часа и на подготовку уходит 5 минут, считается, что эксперт выполняет 115 минут работы исключительно по разметке попарных сравнений.

Тогда максимальное количество сравнений, которое эксперт может выполнить за один сеанс:
\[
N_{\text{max}} = \frac{T_{\text{work}}}{\tau} = \frac{115}{0.7} \approx 164.
\]

Необходимое количество сеансов для выполнения \(N\) сравнений:

\[
S = \left\lceil \frac{N}{N_{\text{max}}} \right\rceil = \left\lceil \frac{N}{164} \right\rceil.
\]

\subsection{Анализ результатов}

Из результатов исследования видно следующее.
\begin{enumerate}
    \item При малом количестве альтернатив ($m$ не более $10$) оба метода требуют сравнимого времени (до 1 часа).
    \item При \(m = 16\) классический МАИ требует 1.6 часа, модификация --- около 0.5 часа (модификация требует меньше времени в 3 раза).
    \item При \(m = 50\) классический МАИ требует 16 часов (более двух рабочих дней), модификация --- 1.3 часа.
    \item При \(m = 100\) классический МАИ требует 64 часа (более недели непрерывной работы), тогда как модификация требует 2.6 часа.
\end{enumerate}

Таким образом, количество времени, необходимого эксперту для разметки попарных сравнений, меньше при использовании модифицированного метода во всех рассмотренных случаях.
Кроме того, разница количества необходимого времени между методами увеличивается с увеличением числа альтернатив.
При малом количестве альтернатив, модифицированный метод требует сравнимого времени по сравнению с классическим методом ---  для 5 альтернатив необходимое время разметки равно, однако при большем числе альтернатив, начиная с 10, превосходство по времени увеличивается с 2 раз до более 10.

\subsection*{Выводы}

В результате исследования можно сделать следующие выводы.

\begin{itemize}
    \item Среднее время разметки одного попарного сравнения составляет \(\tau \approx 42\) секунды.
    \item Предложенная модификация МАИ позволяет дополнительно сократить временные затраты эксперта при увеличении числа альтернатив.
    \item Для задач с 16-30 альтернативами модификация требует в 3-6 раз меньше времени по сравнению с классическим МАИ.
    \item Для задач с 50-100 альтернативами разница становится более существенной: модификация требует в 10-25 раз меньше времени.
    \item Рекомендуется использовать модификацию МАИ во всех задачах, где число альтернатив превышает 10, а группировка альтернатив является по мнению экспертов нетрудозатратной операцией.
\end{itemize}

\section{Параметризация разработанного метода}

В данном исследовании будет рассматриваться зависимость качества выдаваемых рекомендаций в зависимости от задаваемых экспертом весов критериев.

\subsection{Исследовательская процедура}

Исследование разработанного метода проводилось в соответствии со следующей процедурой.

\begin{enumerate}
\item Формирование набора тестовых сценариев в выбранном домене (приготовление пищи).
\item Определение набора возможных аварийных ситуаций.
\item Дополнение набора инструкций графами аварийных сценариев, определение начальных и конечных состояний в них, а также возможности возврата к предыдущей инструкции из графа по завершении выполнения.
\item Определение набора уровней экспертизы оператора.
\item Заполнение экспертом каждого уровня экспертизы соответствующими весами критериев.
\item Выбор уровня экспертизы из описанных.
\item Проведение серии испытаний с базовой конфигурацией весов рекомендаций.
\item Экспертная оценка качества выдаваемых рекомендаций по шкале от 1 до 3.
\item Настройка экспертом весов рекомендаций по критериям.
\item Повторная экспертная оценка качества выдаваемых рекомендаций после настройки.
\item Сравнение результатов и формулирование выводов.
\end{enumerate}

\subsection{Набор сценариев развития событий}

Ввиду большого числа %распаршенных студентами кафедры, включая меня :)
открыто доступных инструкций для исследования выбран кулинарный домен. 

Для каждой решаемой задачи в рамках домена <<Приготовление пищи>> были разработаны сценарии, включающие как штатное, так и нештатное развитие событий. 
Такой подход позволяет оценить не только работу реализации предложенного метода в нормальных условиях, но и обработку нештатных ситуаций, требующих принятия дополнительных решений.

\subsection*{Сценарий 1: Приготовление кофе}

\textbf{Штатный сценарий} включает последовательное выполнение пяти действий: налить воду в чайник, вскипятить воду, налить кипяток в кружку, добавить кофе, перемешать.

\textbf{Нештатные ситуации.}
\begin{itemize}
\item \textit{Пролив воды} --- при выполнении действия <<Налить воду в чайник>> оператор проливает воду на стол или пол.
\item \textit{Перегрев чайника} --- при кипячении воды чайник перегревается, начинает дымить. 
\item \textit{Разбитая кружка} --- при добавлении кофе оператор роняет и разбивает кружку.
\end{itemize}

\subsection*{Сценарий 2: Жарка яичницы}

\textbf{Штатный сценарий} включает восемь действий: поставить сковороду на плиту, включить плиту, нагреть сковороду, добавить масло, разбить яйца, дождаться готовности, выключить плиту, подать на тарелку.

\textbf{Нештатные ситуации.}
\begin{itemize}
\item \textit{Возгорание масла} --- при нагреве масла на сковороде оно воспламеняется.
\item \textit{Ожог рук} --- оператор касается горячей ручки сковороды. 
\item \textit{Яйца с осколками скорлупы} --- при разбивании яиц скорлупа попадает в блюдо. 
\end{itemize}

\subsection*{Сценарий 3: Варка компота}

\textbf{Штатный сценарий} включает восемь действий: поставить кастрюлю на плиту, налить воду, вскипятить воду, подготовить фрукты, добавить фрукты, добавить сахар, варить компот, разлить по кружкам.

\textbf{Нештатные ситуации.}
\begin{itemize}
\item \textit{Выкипание воды} --- вода полностью выкипела, кастрюля остается сухой.
\item \textit{Порез при нарезке фруктов} --- оператор порезал руку ножом. 
\item \textit{Испорченные фрукты} --- фрукты оказались непригодными для использования. 
\end{itemize}

Таким образом, каждый из трех сценариев включает в себя от одной до трех нештатных ситуаций.

\subsection{Экспертная оценка результатов}

Каждый эксперт оценивал качество выдаваемых рекомендаций по шкале:
\begin{itemize}
\item 1 --- плохо (рекомендации нерелевантны, мешают выполнению);
\item 2 --- приемлемо (рекомендации в целом уместны, но не всегда полезны, выдаются в неверном порядке);
\item 3 --- хорошо (рекомендации точны, полезны, повышают безопасность и качество выполнения, выдаются в правильном порядке).
\end{itemize}

Оценки усреднялись по трем сценариям (кофе, яичница, компот) и по нескольким действиям в каждом сценарии.
