\chapter{Исследовательский раздел}

\section{Исследовательская процедура}

Исследование разработанного метода поддержки принятия решений проводилось в соответствии со следующей процедурой.

\begin{enumerate}
    \item Формирование набора тестовых сценариев, включающих штатные и нештатные ситуации в выбранном домене (кулинарные рецепты).
    \item Параметризация метода --- выбор диапазонов значений ключевых параметров для экспериментов.
    \item Проведение серии экспериментов с различными значениями параметров.
    \item Экспертная оценка качества выдаваемых рекомендаций по шкале от 1 до 3.
    \item Анализ результатов и формулирование рекомендаций по выбору оптимальных параметров.
\end{enumerate}

\section{Набор сценариев развития событий}

Исследование проводилось на основе трех базовых сценариев в домене <<Кулинарные рецепты>>, каждый из которых допускал штатное и нештатное развитие событий.

\subsection{Сценарий 1: Приготовление кофе}

\textbf{Штатный сценарий.}
\begin{enumerate}
    \item Налить воду в чайник.
    \item Вскипятить воду.
    \item Налить кипяток в кружку.
    \item Добавить кофе.
    \item Перемешать.
\end{enumerate}

\textbf{Нештатные ситуации.}
\begin{itemize}
    \item Пролил воду на стол / пол (авария).
    \item Разбил кружку (авария).
    \item Чайник перегрелся, дымит (критическая авария).
    \item Обжёгся паром (требует медицинской помощи).
\end{itemize}

\subsection{Сценарий 2: Жарка яичницы}

\textbf{Штатный сценарий.}
\begin{enumerate}
    \item Поставить сковороду на плиту.
    \item Включить плиту.
    \item Нагреть сковороду.
    \item Добавить масло.
    \item Разбить яйца.
    \item Дождаться готовности.
    \item Выключить плиту.
    \item Подать на тарелку.
\end{enumerate}

\textbf{Нештатные ситуации.}
\begin{itemize}
    \item Масло загорелось (пожар).
    \item Яйца разбиты с осколками скорлупы.
    \item Обжёгся о ручку сковороды.
    \item Яйца подгорели, дым.
\end{itemize}

\subsection{Сценарий 3: Варка компота}

\textbf{Штатный сценарий:}
\begin{enumerate}
    \item Поставить кастрюлю на плиту.
    \item Налить воду.
    \item Вскипятить воду.
    \item Подготовить фрукты (вымыть, нарезать).
    \item Добавить фрукты.
    \item Добавить сахар.
    \item Варить компот.
    \item Разлить по кружкам.
\end{enumerate}

\textbf{Нештатные ситуации.}
\begin{itemize}
    \item Вода выкипела, кастрюля сухая.
    \item Порезался при нарезке фруктов.
    \item Фрукты испорчены (не хватает ингредиентов).
    \item Компот убежал, залил плиту.
\end{itemize}

\subsection{Сценарии для исследования модифицированного МАИ}

Для исследования эффективности модифицированного МАИ были подготовлены дополнительные сценарии ранжирования альтернатив (рекомендаций) с различным количеством элементов и структурой групп:

\begin{itemize}
    \item \textbf{сценарий A}: 5 альтернатив, одна группа (фактически полный перебор);
    \item \textbf{сценарий B}: 16 альтернатив, разбитых на 3 группы (размеры 5, 6, 5), глубина вложенности групп 2 (группы верхнего уровня содержат подгруппы);
    \item \textbf{сценарий C}: 16 альтернатив, те же группы, но глубина вложенности групп 3;
    \item \textbf{сценарий D}: 100 альтернатив, разбитых на 10 групп по 10 элементов, глубина 2;
    \item \textbf{сценарий E}: 100 альтернатив, 10 групп, внутри каждой --- вложенные подгруппы (глубина 3).
\end{itemize}

\section{Экспертная оценка результатов}

Для каждого сочетания параметров эксперт (автор работы) оценивал качество выдаваемых рекомендаций по шкале:
\begin{itemize}
    \item 1 --- плохо (рекомендации нерелевантны, мешают выполнению);
    \item 2 --- нормально (рекомендации в целом уместны, но не всегда полезны);
    \item 3 --- хорошо (рекомендации точны, полезны, повышают безопасность и качество выполнения).
\end{itemize}

\section{Рекомендации о применимости метода}

На основе проведённого исследования сформулированы следующие рекомендации:

\subsection{Выбор метода МАИ}

\begin{itemize}
    \item При количестве альтернатив (рекомендаций) до 10 рекомендуется использовать \textbf{полный МАИ} (класс \texttt{FullAHP}) --- максимальная точность, число сравнений невелико.
    \item При количестве альтернатив от 10 до 50 и наличии естественной группировки рекомендуется \textbf{модифицированный МАИ}.
    Это даёт приемлемую точность (оценка 2.5-2.7) при сокращении числа сравнений в 2-10 раз.
    \item При количестве альтернатив свыше 50 только групповой МАИ остаётся практически применимым, хотя точность падает до 2.0-2.3.
\end{itemize}

\subsection{Настройка параметров}

\begin{itemize}
    \item Порог согласованности CR = 0.10 (стандартное значение Саати) является оптимальным и не требует изменения.
    \item Максимальная глубина рекурсии аварийных сценариев = 3 --- достаточна для покрытия большинства реальных ситуаций.
    \item Количество выводимых рекомендаций top\_n = 3 --- оптимально для пользовательского интерфейса (больше трёх перегружают, меньше --- недостаточно информации).
\end{itemize}

\subsection{Выбор профиля экспертизы}

\begin{itemize}
    \item Для обучающих систем и приложений для широкой аудитории --- профиль<<Новичок>>.
    \item Для общего использования --- профиль<<Опытный>> (рекомендуется по умолчанию).
    \item Для профессиональных пользователей (повара, технологи) --- профиль<<Эксперт>>.
\end{itemize}

\subsection{Ограничения метода}

\begin{itemize}
    \item Метод не рекомендуется для задач, требующих мгновенной реакции (хирургия, управление БПЛА), так как интерактивный режим вносит задержки.
    \item При часто меняющемся контексте (например, динамические рецепты) требуется частая перенастройка меток и оценок, что увеличивает нагрузку на эксперта.
    \item Модифицированный МАИ требует заранее определённое разделение на группы; если группировка неочевидна, лучше использовать полный МАИ.
\end{itemize}

\subsection{Практическая применимость}

Разработанный метод и программная система могут быть рекомендованы для следующих доменов.
\begin{itemize}
    \item Кулинарных приложений и умных кухонь (помощь при готовке).
    \item Обучающих систем (пошаговое обучение с подсказками).
    \item Промышленных инструкций (сборка оборудования, настройка станков) --- с доработкой интерфейса.
    \item Бытовая помощь пожилым людям и людям с ограниченными возможностями.
\end{itemize}

\section{Выводы по исследовательскому разделу}

Проведённое исследование подтвердило работоспособность и эффективность разработанного метода поддержки принятия решений. Экспертная оценка показала:
\begin{itemize}
    \item Полный МАИ даёт максимальную точность, но требует значительного числа сравнений при большом количестве альтернатив;
    \item Модифицированный МАИ обеспечивает приемлемую точность (оценка 2.5-2.7) при сокращении числа сравнений в 3-10 раз, что делает его предпочтительным для задач с большим числом альтернатив;
    \item Порог согласованности CR = 0.10, глубина рекурсии аварий = 3, top\_n = 3 --- оптимальные параметры;
    \item Профиль <<Опытный>> является наилучшим для большинства пользователей.
\end{itemize}

Таким образом, метод может быть рекомендован к практическому использованию в задачах пошагового обучения и поддержки принятия решений в различных доменах.
